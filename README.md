# Reverse Engineering for Python Programmers

A free, self-paced course for people who know Python but have no computer science background. It is a single interactive HTML page with eight modules, curated readings, videos, tools, Python exercises, and short quizzes.

## Contents

| # | Module |
|---|--------|
| 1 | Start here: ethics and a safe lab |
| 2 | How programs live in memory |
| 3 | Reading C (not writing it) |
| 4 | Reading assembly (x86-64) |
| 5 | Your toolkit: Ghidra, a debugger, and friends |
| 6 | Practice: crackmes and CTFs |
| 7 | Python as a reversing weapon |
| 8 | Choose a specialty and keep going |

Each module includes a goal, a time estimate, a Python exercise, filterable resources (reading, video, course, tool, practice), and a self-check quiz. The suggested pace is roughly 8 to 10 weeks at a few hours a week. That estimate is a rough guide, not a measured figure.

## Usage

1. Download `index.html`.
2. Open it in any modern browser. There is no build step or server, and nothing to install.

Your progress (completed modules) is saved in your browser's local storage on your own device. Nothing is sent anywhere.

## Prerequisites

- Basic Python
- A Linux virtual machine for the practical modules (the course explains how to set one up)

## Notes on the links

Resource links point to third-party sites and may change or disappear over time. If you find a broken or outdated link, please open an issue or a pull request.

Corrections, new resources, and additional exercises are welcome. Please keep exercises in Python and prefer free resources where possible.
